# Palette's Journal - Halal Kuri Management System

## 2025-05-18 - Password Visibility Toggle UX in Secure Forms
**Learning:** In private/invited community systems with strict password credentials and no self-service signups, password visibility toggles on login forms significantly reduce authentication failures due to typos without exposing security risks.
**Action:** Always provide explicit accessible `aria-label`s on visibility toggle buttons, along with `pr-10` padding on the input to avoid visual clipping of characters against the icon.
