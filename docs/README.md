# Halal Kuri Management System

## Project Overview

Welcome to the **Halal Kuri Management System**.

This project is a **private, invitation-only Halal Kuri (Islamic Interest-Free Committee) management platform** built with modern web technologies.

The goal is to create a premium, mobile-first, responsive web application for managing members, contributions, recipients, announcements, and reports while maintaining transparency and simplicity.
